# 王志成的个人网站

一个长期维护的个人网站，用来呈现做过的产品、形成的判断、生活经历与持续写下来的记录。

访问：<https://zachsaws.github.io/>

## 本地运行

```bash
npm install
npm run dev
```

## 构建

```bash
npm run lint
npm run build
```

网站由 GitHub Actions 自动构建并发布到 GitHub Pages。
